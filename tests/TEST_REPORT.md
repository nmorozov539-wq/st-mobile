## Repairs exposed by these sequences

1. The queue persisted rebased settings guards but iterated stale in-memory records. Dispatch now reads each durable item again; only components changed by our own verified writes are rebased. External conflicts remain guarded.
2. ST adds native swipe/message metadata when opening an older chat. Before Send, Pocket adopts that native snapshot for the displayed originating target, so earlier queued edits use the captured history.
3. Undo restored disk but left the native runtime deleted. A subsequent fork/switch could overwrite the restored original. Undo now reloads the verified restored history into ST; multi-delete → Undo → Fork is checked end to end.
4. Review could be tapped before the replacement connection was ready. It is disabled through disconnect/initialization, and immediate reconnect/review is tested.
5. Touch capture transfer from a child must not cancel the parent gesture. Capture cleanup distinguishes its actual target. Scroll handling also avoids replacing messages when no unrendered neighbor exists, protecting selection and gesture continuity.
